# Recomp — Lean Fitness Tracker

A local-first Next.js fitness tracker for the plan in the supplied Lean Skinny-Fat guide.

## Included
- Dashboard with calories, protein, water, steps and sleep
- Daily check-in for weight, waist, water, steps and sleep
- 4-day Upper/Lower workout plan
- Exercise completion checklist
- Set logging with weight × reps
- Meal logging with calories + protein
- Weight trend / 14-day average
- LocalStorage persistence (no account or database required)
- Responsive dark UI

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

Data stays in the browser's localStorage. This starter intentionally avoids a backend so it is easy to run and customize.
